01 · Clause to code

Every number keeps its source.

Each clause becomes a value. Each value carries its clause. Any figure can be checked against the page it came from. Where the document is unclear, the value is left blank.

key: "orv3",
// OCP Open Rack Base Frame V3, rev 1.1
unit: 48,  unitName: "OU",     // §6.1.2
panel: 540.40, overallWidth: 600.24, // Fig 6.1.1
holes: [9, 33],                 // Fig 6.1.2.1
bore: 4.5, frontBore: 5.4,     // Fig 6.1.2.2
square: null,   // no cage-nut hole
depth: 1068.24, shelfStop: 789.0

Morphit

Standards become code. Drawings become models.

Infrastructure is specified in documents and built from drawings. Morphit joins the two. A change of standard takes seconds, not weeks.

  • Parametric. Change one value. Rebuild only what follows.
  • Sourced. Every standard figure cites its clause.
  • Standards. EIA-310-E, OCP ORv3, AISC HSS, ASME B36.10M.
  • Elements. Racks, trusses, trays, busway, pipe.
  • Repetition. Copies of copies. One edit.
  • Clashes. Found in solids, not on site.
  • Engineering. Load, current and heat, on every part.
  • Quantities. Straight from the model.
  • In the browser. No install. No server.
  • Readable. A specification in. Parameters out.
